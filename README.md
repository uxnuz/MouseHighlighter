# 마우스 강조 (MouseHighlighter)

화면 녹화, 발표, 원격 지원을 할 때 **마우스 커서 위치와 클릭을 눈에 잘 띄게 보여 주는** Windows 프로그램입니다.

- **커서 강조**: 커서 주변에 반투명한 원이 따라다닙니다.
- **클릭 효과**: 클릭한 자리에서 물결이 퍼집니다. 왼쪽, 오른쪽, 휠 클릭마다 색이 다릅니다.
- **설정 창**: 색, 범위(크기), 투명도를 바꿀 수 있고, 효과별로 켜고 끌 수 있습니다. 배경색별로 잘 보이는지 확인하는 클릭 테스트 영역도 있습니다.
- 효과 창은 클릭이 그대로 통과하고 포커스를 뺏지 않아서, 다른 프로그램을 쓰는 데 방해가 되지 않습니다.

---

## 사용하는 분께

### 실행
> GitHub에서 받는 경우: 오른쪽의 **Releases** 에서 `MouseHighlighter.exe` 를 내려받으세요. exe는 용량(약 72MB) 때문에 코드와 따로 올려 두었습니다.

1. 폴더 맨 위에 있는 **`MouseHighlighter.exe`** 를 더블클릭합니다. 설치할 필요가 없고, .NET도 따로 설치하지 않아도 됩니다.
2. 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르세요. 코드 서명이 안 된 프로그램이라서 뜨는 경고입니다.
3. 작업 표시줄 오른쪽 트레이에 화살표 모양 아이콘이 생깁니다. 아이콘이 안 보이면 `^`(숨겨진 아이콘)를 눌러 보세요.

### 트레이 아이콘 메뉴 (우클릭)
| 메뉴 | 하는 일 |
|---|---|
| **설정** | 설정 창을 엽니다 |
| 강조 켜기/끄기 | 모든 효과를 한꺼번에 켜고 끕니다. 아이콘을 더블클릭해도 됩니다 |
| 종료 | 프로그램을 끝냅니다 |

### 설정 창
- **커서 강조 / 클릭 효과 체크박스**: 효과를 하나씩 끌 수 있습니다. 꺼 둔 효과는 CPU를 전혀 쓰지 않습니다.
- **색**: 색 상자를 누르면 색을 고르는 창이 열립니다.
- **범위(크기)·투명도**: 슬라이더로 조절하거나 숫자를 직접 입력합니다.
  - Enter를 누르거나 다른 곳을 클릭하면 적용됩니다. Esc를 누르면 취소됩니다.
  - ↑/↓ 키로 1씩, Shift+↑/↓로 10씩 바꿀 수 있습니다.
  - 투명도는 **0% = 가장 진함, 100% = 안 보임** 입니다.
- **클릭 테스트 ▶** (오른쪽 위): 누르면 창이 넓어지면서 테스트 영역이 나옵니다. 아래에서 노랑, 빨강, 검정, 하양, 초록 배경을 골라, 어떤 배경에서 효과가 잘 보이는지 확인할 수 있습니다.
- **기본값으로**: 처음 설정으로 되돌립니다.
- 설정은 창을 닫을 때 저장되고, 다음에 실행할 때도 유지됩니다.

### 자주 묻는 질문
- **두 번 실행하면?** 이미 실행 중이면 새로 뜨지 않습니다. 트레이 아이콘을 확인하세요.
- **설정을 완전히 초기화하려면?** 프로그램을 종료한 뒤 `%AppData%\MouseHighlighter` 폴더를 지우세요. 탐색기 주소창에 그대로 붙여 넣으면 열립니다.
- **Windows가 켜질 때 자동으로 실행하려면?** `Win + R` → `shell:startup` 을 입력해 열리는 폴더에 `MouseHighlighter.exe` 의 바로 가기를 넣으세요.

### 빠른 시작
- 필요한 것: [.NET SDK 10](https://dotnet.microsoft.com/download) 이상. Visual Studio 2022 이상이나 VS Code를 쓰면 편하지만 꼭 필요하지는 않습니다.
- **코드를 고친 뒤 `exe 다시 만들기.bat` 을 더블클릭**하면 폴더 맨 위의 `MouseHighlighter.exe` 가 새로 만들어집니다.
- 개발 중에 빠르게 실행해 보려면:
  ```bash
  dotnet run --project MouseHighlighter.csproj -- --settings
  ```
  `--settings` 를 붙이면 시작하자마자 설정 창이 열립니다.

### 폴더 구성
```
MouseHighlighter/
├─ MouseHighlighter.exe        ← 공유용 실행 파일 (이것만 있으면 실행됨)
├─ exe 다시 만들기.bat          ← 코드를 고친 뒤 exe를 다시 만드는 스크립트
├─ README.md                   ← 이 문서
├─ docs/                       ← 참고 문서
├─ CLAUDE.md                   ← AI 코딩 도구(Claude Code 등)용 요약 안내
├─ App.cs                      ← 시작점, 트레이 아이콘, 켜기/끄기 판단
├─ Settings.cs                 ← 설정값, 기본값, 저장/불러오기
├─ OverlayWindows.cs           ← 커서 원과 클릭 물결 (화면에 그리는 부분)
├─ MouseHook.cs                ← 전역 마우스 클릭 감지
├─ NativeMethods.cs            ← Windows API 호출
├─ TrayIcon.cs                 ← 트레이 아이콘 이미지 만들기
├─ SettingsWindow.xaml(.cs)    ← 설정 창 (화면 배치 / 동작)
├─ app.manifest                ← 고해상도(DPI) 설정
├─ MouseHighlighter.csproj     ← 프로젝트 설정
└─ Properties/PublishProfiles/Share.pubxml  ← 공유용 exe 만들기 설정
```
