# 수정 가이드

자주 하는 수정 방법, 빌드와 배포, 문제 해결 방법을 모았습니다.
코드 구조와 설계 이유는 [구조.md](구조.md)를 먼저 읽으면 이해가 빠릅니다.

---

## 1. 개발 환경

- **필수**: [.NET SDK 10](https://dotnet.microsoft.com/download) 이상 (Windows)
- **있으면 편함**: Visual Studio 2022 이상(`MouseHighlighter.csproj` 를 열면 됨), 또는 VS Code + C# 확장
- SDK가 설치되어 있는지 확인:
  ```bash
  dotnet --list-sdks
  ```

### 실행해 보기 (개발 중)
```bash
dotnet run --project MouseHighlighter.csproj -- --settings
```
- `--settings`: 시작하자마자 설정 창을 엽니다.
- 이미 실행 중인 MouseHighlighter가 있으면 새로 뜨지 않습니다. 트레이에서 먼저 종료하세요. 한 번에 하나만 실행되게 막아 두었습니다.
- 이렇게 실행하면 `bin/`, `obj/` 폴더가 생깁니다. 지워도 괜찮고, `exe 다시 만들기.bat` 을 실행하면 자동으로 정리됩니다.

### 공유용 exe 만들기
- **`exe 다시 만들기.bat` 더블클릭.** 실행 중인 앱을 종료하고, exe를 빌드한 뒤, 빌드 중간 파일을 정리합니다.
- 명령으로 직접 하려면:
  ```bash
  dotnet publish MouseHighlighter.csproj -p:PublishProfile=Share
  ```
  결과물은 폴더 맨 위의 `MouseHighlighter.exe` 입니다. `bin\share\` 에 만든 뒤 맨 위로 복사됩니다.

### 공유하기
- 폴더를 통째로 압축해서 공유하면 됩니다. 쓰기만 하는 사람에게는 `MouseHighlighter.exe` 하나만 줘도 됩니다.
- 압축하기 전에 `bin/`, `obj/` 폴더가 있으면 지우세요. `exe 다시 만들기.bat` 을 실행했다면 이미 지워져 있습니다.
- 개인 설정 파일은 `%AppData%` 에 있어서 압축 파일에 들어가지 않습니다.

## 2. 자주 하는 수정

### 2-1. 기본값 바꾸기
`Settings.cs` 의 속성 초기값을 고칩니다.
```csharp
public string CircleColor { get; set; } = "#FFE600";   // ← 원하는 색으로
public double CircleDiameter { get; set; } = 60;       // ← 원하는 크기로
```
- 기본값은 **설정 파일이 없을 때**(처음 실행할 때)와 **'기본값으로'를 눌렀을 때**만 쓰입니다.
- 이미 쓰던 사람은 저장된 값이 우선입니다. 바뀐 기본값을 확인하려면 설정 창에서 '기본값으로'를 누르세요.

### 2-2. 설정 창에 슬라이더 항목 추가하기
예시: 설정 창에 없는 `RippleDurationMs`(물결이 사라지는 시간)를 슬라이더로 조절하게 만들기.

**① `Settings.cs`**: 속성이 없으면 추가합니다. 이 예시에서는 이미 있습니다.
```csharp
public int RippleDurationMs { get; set; } = 450;
```

**② `SettingsWindow.xaml`**: 클릭 효과 섹션의 '투명도' 줄 아래에 한 줄을 추가합니다. 기존 줄을 복사해서 이름만 바꾸면 됩니다.
```xml
<DockPanel>
    <TextBlock Text="지속 시간" Style="{StaticResource RowLabel}" />
    <TextBlock Text="ms" Style="{StaticResource Unit}" />
    <TextBox x:Name="RippleDurationBox" Style="{StaticResource NumberBox}"
             Tag="{Binding ElementName=RippleDurationSlider}" ToolTip="100 ~ 2000" />
    <Slider x:Name="RippleDurationSlider" Minimum="100" Maximum="2000" ValueChanged="OnSliderChanged" />
</DockPanel>
```
- 숫자 입력 칸은 `Tag` 에 연결된 슬라이더를 움직이는 방식이라, **숫자 입력 처리는 따로 만들 필요가 없습니다.**
- 순서가 중요합니다. 단위 → 입력 칸 → 슬라이더 순서로 둬야 오른쪽부터 차례로 붙습니다(DockPanel 규칙).

**③ `SettingsWindow.xaml.cs`**: 세 군데에 한 줄씩 추가합니다.
```csharp
// LoadValues(): 설정 → 슬라이더
RippleDurationSlider.Value = s.RippleDurationMs;

// RefreshLabels(): 설정 → 숫자 칸
RippleDurationBox.Text = $"{s.RippleDurationMs}";

// OnSliderChanged(): 슬라이더 → 설정
s.RippleDurationMs = (int)Math.Round(RippleDurationSlider.Value);
```

**④ 값을 실제로 쓰는 곳**을 확인합니다. `RippleWindow` 는 이미 `s.RippleDurationMs` 를 읽고 있으므로 이 예시에서는 할 일이 없습니다.
커서 원에 쓰는 값이라면 `CursorCircleWindow.ApplySettings()` 에서 읽게 하세요.

### 2-3. 색 선택 항목 추가하기
1. `Settings.cs` 에 `string` 속성을 추가합니다(예: `"#FFFFFF"`).
2. `SettingsWindow.xaml` 에서 색 버튼 줄을 복사해 `Tag` 값과 `Border` 의 `x:Name` 을 새 이름으로 바꿉니다.
3. `SettingsWindow.xaml.cs` 의 `OnColorButtonClick()` 에서 두 `switch` 에 새 `Tag` 를 추가하고, `RefreshLabels()` 에서 색 상자를 칠하는 줄을 추가합니다.

### 2-4. 클릭 테스트 배경색 추가/변경
`SettingsWindow.xaml` 의 클릭 테스트 영역에서 `RadioButton` 한 줄을 추가하거나 고치면 됩니다. 코드는 고칠 필요가 없습니다.
```xml
<RadioButton Content="파랑" Background="#1E88E5" Style="{StaticResource BackgroundChoice}" />
```
테스트 영역의 너비는 `TestPanel` 의 `Width="320"` 입니다. 색을 많이 넣으면 이 값도 늘리세요.

### 2-5. 트레이 메뉴 항목 추가
`App.cs` 의 `CreateTrayIcon()` 에서 항목을 만들어 `menu.Items` 에 넣습니다.
```csharp
var aboutItem = new Forms.ToolStripMenuItem("정보");
aboutItem.Click += (_, _) => System.Windows.MessageBox.Show("마우스 강조 v1.0");
menu.Items.Add(aboutItem);
```
WPF와 WinForms 모두에 `MessageBox` 가 있어서, 이름을 끝까지(`System.Windows.MessageBox`) 적어야 합니다.

### 2-6. 감지할 마우스 동작 추가 (버튼 떼기, 휠 등)
1. `NativeMethods.cs` 에 메시지 상수를 추가합니다. 예: `WM_LBUTTONUP = 0x0202`, `WM_MOUSEWHEEL = 0x020A`
2. `MouseHook.HookCallback()` 에서 분기를 추가하고, 필요하면 새 이벤트(예: `ButtonUp`)를 만듭니다.
3. `App.UpdateActiveState()` 에서 훅을 만들 때 새 이벤트를 연결합니다.
4. 휠 방향은 `MSLLHOOKSTRUCT.mouseData` 의 위쪽 16비트에 있습니다. 양수는 위로, 음수는 아래로 굴린 것입니다.

> 훅 콜백 안에서는 무거운 작업을 하지 마세요. 콜백이 늦으면 PC 전체의 마우스가 버벅입니다.

### 2-7. 효과 모양 바꾸기
- **커서 원**: `OverlayWindows.cs` → `CursorCircleWindow.ApplySettings()`. 테두리를 진하게 하는 배율 `* 2.5` 도 여기 있습니다.
- **클릭 물결 애니메이션**: `RippleWindow` 의 `Loaded` 처리기. 시작 크기 `0.2`, 끝 크기 `1.0`, 감속 방식(`QuadraticEase`)을 바꿀 수 있습니다.
- 모양을 원이 아닌 것으로 바꾸려면 `Ellipse` 대신 `Rectangle` 이나 `Path` 를 쓰면 됩니다. 창 크기가 모양을 다 담을 만큼 커야 합니다.

### 2-8. 트레이 아이콘 바꾸기
`TrayIcon.cs`. 지금은 Windows의 현재 화살표 커서를 가져다 씁니다. 그래서 사용자가 커서 모양을 바꿔 두었다면 그 모양이 아이콘으로 보입니다.
직접 만든 `.ico` 파일을 쓰려면:
1. `.ico` 파일을 프로젝트에 넣고, `csproj` 에 `<EmbeddedResource Include="app.ico" />` 를 추가합니다.
2. `App.CreateTrayIcon()` 에서 `Icon = new System.Drawing.Icon(typeof(App).Assembly.GetManifestResourceStream("MouseHighlighter.app.ico")!)` 처럼 읽습니다.

> 파일 경로로 읽지 말고 exe 안에 넣어 두세요(EmbeddedResource). 그래야 exe만 따로 옮겨도 동작합니다.

## 3. 꼭 지켜야 할 것

| 규칙 | 이유 |
|---|---|
| **exe 옆의 파일을 경로로 읽지 않기.** 필요한 파일은 EmbeddedResource로 넣고, 저장할 파일은 `%AppData%` 에 두기 | 공유용 exe는 단일 파일이라 옆에 다른 파일이 없습니다. `Assembly.Location` 은 단일 파일에서 빈 문자열입니다. 경로가 필요하면 `AppContext.BaseDirectory` 를 쓰세요 |
| **효과 창은 `OverlayWindow` 를 상속하기** | 클릭 통과, 포커스 안 뺏기, 화면 밖에서 시작하기가 여기에 들어 있습니다 |
| **효과 창 위치는 `NativeMethods.CenterWindowAt()` 으로 옮기기** (`Left`/`Top` 사용 금지) | 모니터 배율이 섞이면 어긋납니다 (구조.md 3-2) |
| **`CompositionTarget.Rendering` 을 구독했으면 끌 때 반드시 해제하기** | 구독하는 동안 CPU를 계속 씁니다 |
| **설정을 바꾼 뒤에는 `Settings.NotifyChanged()` 호출하기** | 호출해야 화면에 바로 반영됩니다 (설정 창에서는 `Apply()` 가 호출해 줌) |
| **훅 콜백(`ButtonDown` 처리기)은 가볍게** | 시스템 전체의 마우스 반응이 느려집니다 |

## 4. 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| `exe 다시 만들기.bat` 이 실패하고 "다른 프로세스에서 사용 중" 이라고 나옴 | exe가 실행 중이라 잠겨 있습니다. 스크립트가 먼저 종료하지만, 다른 계정이나 관리자 권한으로 실행 중이면 직접 종료하세요 |
| 빌드 오류 `CS5001 Main 메서드가 없음` | `PublishDir` 을 프로젝트 폴더 자체로 바꾸면 생깁니다. `Share.pubxml` 의 `bin\share\` 설정을 유지하세요 |
| 실행했는데 아무것도 안 보임 | 이미 실행 중일 수 있습니다(트레이 확인). 트레이에서 '강조 켜기/끄기'가 꺼져 있거나, 설정에서 효과 체크가 풀려 있을 수도 있습니다 |
| 설정이 이상해서 처음부터 다시 하고 싶음 | 앱을 종료한 뒤 `%AppData%\MouseHighlighter\settings.json` 을 지우세요 |
| 설정을 바꿨는데 다음 실행 때 사라짐 | 설정 창을 닫거나 트레이 '종료'로 끝낼 때 저장됩니다. 작업 관리자로 강제 종료하면 저장되지 않습니다 |
| 트레이 아이콘이 안 보임 | 작업 표시줄의 `^`(숨겨진 아이콘) 안에 있습니다. 작업 표시줄로 끌어다 놓으면 항상 보입니다 |
| "Windows의 PC 보호" 경고 | 코드 서명이 없어서 뜹니다. **추가 정보 → 실행**을 누르세요 |

## 5. 알려진 제한 사항

- **잠금 화면, UAC(관리자 권한 확인) 창 위에서는 효과가 보이지 않습니다.** Windows가 이런 화면을 별도의 보안 화면으로 띄우기 때문입니다.
- **관리자 권한으로 실행한 프로그램 위에서는 클릭 효과가 동작하지 않거나 원이 가려질 수 있습니다.** Windows가 권한이 낮은 프로그램의 간섭을 막기 때문입니다. 필요하면 MouseHighlighter도 관리자 권한으로 실행해 보세요.
- **전체 화면 '독점 모드' 게임** 위에는 보이지 않을 수 있습니다. 창 모드나 테두리 없는 창 모드에서는 보입니다.
- 배율이 다른 모니터 사이를 넘어갈 때 원 크기가 잠깐 어긋날 수 있습니다.
- 커서 강조를 켜 두면 가만히 있을 때도 CPU를 코어 하나의 약 3% 정도 씁니다(구조.md 3-4). 끄면 0입니다.
- 공유용 exe는 약 72MB입니다. .NET이 통째로 들어 있기 때문입니다(구조.md 3-7).
- 코드 서명이 없어서, 처음 실행할 때 SmartScreen 경고가 뜹니다.
